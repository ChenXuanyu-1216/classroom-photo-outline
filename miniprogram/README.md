# 课照大纲助手 · 微信小程序

这是原生微信小程序源码，包含上传照片、处理进度、大纲校对、整理记录四个业务页面，以及网页微信扫码登录的确认页。直接导入本文件所在的 `miniprogram` 文件夹，不需要 npm 安装或前端构建。网页与小程序共用 Python 后端和账号资料。

## 云托管模式（联调中）

在 config.js 的 cloud.env 填写控制台真实环境 ID，cloud.service 填写你部署的服务名称；两个字段默认留空；不能用环境名称 prod 代替 ID。开发版默认 HTTP 联调，可将 developmentTransport 设为 cloud 测试云调用；体验版/正式版强制使用云环境，忽略缓存的局域网地址，缺配置时在页面提示并停止请求。

云端登录和 API 使用 wx.cloud.callContainer；照片、原图和 Word 通过带会话的 256 KiB 分块协议传输。保留断线上传标识以便手动重试，不自动重放生成请求。下载副本保存在小程序私有目录，按账号、有效期及 64 MiB/10 文件上限清理。文件不需要公开 COS 链接。

SDK 每个运行平台只执行一次 `wx.cloud.init()`；云托管环境 ID 只在每次 `callContainer.config.env` 中指定，避免将它作为全局云开发初始化环境。切换目标仍按环境和账号隔离会话与草稿。初始化后的首次调用报错时，先重新编译并检查运行中 AppID 与环境所属 AppID，再读取安全错误码；不能因模拟调用通过而宣称已完成真实云调用验收。参考[微信官方小程序访问说明](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloudrun/src/development/call/mini.html)。

先完成[后端资源、迁移、后台执行与恢复验收](../docs/wechat-cloud-hosting.md)，确认小程序与环境绑定，再编译体验版。真实部署状态由运行者自行验证；离线模拟云调用通过不能证明真机、非开发者或平台权限已验收。公网网站入口另行配置，仍访问同一后端。

已接入微信登录与任务归属隔离；配置、旧记录认领和网页版访问方式见[微信登录说明](../docs/wechat-auth.md)。

选图使用 `wx.chooseMedia`（仅图片），老版本才使用 `wx.chooseImage`。小程序后台的“用户隐私保护指引”必须如实声明处理用户信息，并包含“选中的照片或视频信息”；否则微信会返回错误码 112，手机相册权限开启也无法解除。客户端会在需要时展示隐私指引阅读及原生“同意并选择照片”按钮，拒绝时不打开相册。

网页版打开 `/login.html` 后，用微信扫描小程序码，在手机确认即可登录现有微信账号、共享同一份课堂资料。二维码版本、手机后端地址与 HTTPS 代理配置见上述说明；电脑本机地址 `127.0.0.1` 不能直接用于手机扫码联调。

## 1. 启动或重启后端

电脑本地调试可以在仓库根目录使用一条命令：

```powershell
.\lecture-syllabus-generator\scripts\start_miniprogram.ps1
```

它会启动或复用局域网可达的 Python 后端、读取当前 `.env` 的模型配置，并仅在本机忽略的 `project.private.config.json` 中关闭开发阶段的域名校验。随后在开发者工具重新编译。日志写入 `backend/data/miniprogram-server*.log`，不会打印密钥，也不会主动提交识别任务。共享的 `project.config.json` 仍保持合法域名校验开启。

脚本会验证实际监听和电脑当前局域网地址；仅 `127.0.0.1` 返回正常不会被当作手机可用。只检查、不启动也不修改项目配置时运行 `powershell -NoProfile -File lecture-syllabus-generator/scripts/start_miniprogram.ps1 -CheckOnly`。它会打印从电脑验证过的手机服务地址，手机需使用该地址并保持网络可达。

需要手动前台运行或重启时，在仓库根目录打开 PowerShell：

```powershell
Set-Location lecture-syllabus-generator/backend
.\.venv\Scripts\python.exe run.py
```

`run.py` 默认监听 `0.0.0.0:8000`，避免每次启动退回仅电脑可访问；反代部署可显式配置 `APP_SERVER_HOST=127.0.0.1`。旧的回环进程需先正常停止后再重启，启动脚本不会擅自终止既有作业。

首次只检查流程时，可以在**单独的 PowerShell 窗口**中使用预设演示内容，避免调用真实模型：

```powershell
Set-Location lecture-syllabus-generator/backend
$env:APP_MODEL_PROVIDER = 'mock'
$env:APP_CLUSTER_PROVIDER = 'rule'
$env:APP_TASK_QUEUE_ENABLED = 'true'
.\.venv\Scripts\python.exe run.py
```

mock 不会识别真实照片，小程序会显示演示提示。关闭这个窗口即不再保留本窗口环境变量。真实识别沿用后端原有 `.env` 配置；不要把模型密钥放进小程序。

## 2. 导入微信开发者工具

1. 打开微信开发者工具，选择小程序的“导入项目”。
2. 目录选择仓库下的 **`miniprogram` 文件夹**，其中应能看到 `project.config.json` 和 `app.json`。
3. 填写你已注册的小程序 **AppID**。源码的 appid 字段留空，必须填入自己的真实 AppID 才能验证微信登录；AppSecret 只放在后端。
4. 使用普通小程序工程；本机调试不要求云环境，云托管模式需要绑定实际云环境。
5. 编译运行。若工具提示基础库不可用，选择工具提供的当前稳定基础库；工程使用普通原生页面和基础 API。

AppID 可在导入时填写，也可以写入 `project.config.json` 的 `appid` 字段。工具生成的 `project.private.config.json` 为本机配置，已在仓库忽略。

## 3. 电脑本地调试

`config.js` 默认后端为 `http://127.0.0.1:8000`。首页底部“服务连接设置”也可修改，保存后覆盖当前设备的默认地址。

仅在本地开发阶段，在开发者工具的项目详情/本地设置中开启“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”对应调试选项。生产工程的 `urlCheck` 保持开启。

首页成功显示后端模型信息后，选择 2—3 张 JPG/PNG 照片，调整顺序，点击“上传并开始整理”。一次选择最多 9 张，可继续追加，本批最多为后端允许的张数与 20 张中的较小值，合计不超过 8MiB。超限时压缩或分批。

## 4. 手机局域网调试

手机的 `127.0.0.1` 指向手机自身，不能访问电脑后端。

1. 电脑和手机连接同一可互访的 Wi-Fi。
2. 正常停止原后端进程，在后端目录运行：

   ```powershell
   .\.venv\Scripts\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
   ```

3. 用 `ipconfig` 查看电脑的局域网 IPv4 地址，在小程序首页连接设置填入 `http://电脑局域网IP:8000`。
4. 允许此 Python 服务通过 Windows 防火墙的专用网络，并使用开发者工具的真机调试能力。若预览模式拒绝 HTTP，使用真机调试或部署 HTTPS；本机“不校验域名”选项不能替代正式域名配置。

局域网调试服务的任务空间与现有网页版共享，请只在可信网络中使用。无需为此开放公网端口。

## 5. 四页功能与恢复方式

| 页面 | 功能 |
| --- | --- |
| 上传照片 | 相册/拍照、预览、排序、移除、后端连接设置、mock 提示 |
| 处理进度 | 查询后台队列、离开后恢复、查看逐页错误、逐页重试、生成大纲 |
| 学习大纲 | 分层阅读、Markdown 编辑、本机草稿、保存、原图来源、Word 预览/转发菜单、重新生成 |
| 整理记录 | 查看后端记录、重开大纲或进度、确认后删除闲置任务 |

“新建整理”和“整理记录”现在是同一工作区内保留内容的两个页签，点击先开始纸张翻页，列表在后台独立读取，已选照片保持不变。从进度页返回也复用此工作区。头部知识图采用原生 Canvas 绘制网页同款曲线、节点及粒子，按屏幕宽度调整布局。

任务进度不显示虚构的百分比；离开页面停止客户端轮询，后端继续。失败页重试只更新该页识别结果，完成后需要点击“根据当前识别重新生成大纲”。重新生成可能调用模型并替换服务器当前大纲，操作前有确认。

上传或生成发生断网时，先回到整理记录检查已有任务，避免重复提交。客户端不自动重发写入请求。后台队列需保持 `APP_TASK_QUEUE_ENABLED=true`。

编辑内容先保留为本机草稿，点击保存才写入服务器；服务器版本号及已加载正文变化会在保存/导出时检查；重新生成复用版本号时也会要求确认更新，避免静默覆盖。Word 导出会先保存本次编辑，再下载并用微信文档预览器打开，手机预览菜单可用于转发/保存；开发者工具中的文档预览能力请以真机为准。

原图按钮通过后端只读接口按任务和页码读取 JPG/PNG。网页版历史记录里的 PDF 无法在此作为照片预览，会显示格式错误提示。阅读模式以原生标题、段落和知识点显示大纲，点击来源页码可打开原图；编辑模式保留 Markdown 原文。页面采用网页版的纸张布局、衬线标题、课堂底稿和知识连线，并提供轻量浮动效果与速度控制；不依赖浏览器 DOM 动画。

## 6. 正式发布前

源码测试不能证明真实云环境、非开发者账号或新照片全流程已经验收。发布前请在自己的环境中逐项核验，并保留实际日期和结果。

- 云托管模式先完成后端资源与后台执行验收，再填写 config.js 的真实环境 ID 并验证绑定。自行部署 HTTPS 则需配置 request / downloadFile 合法域名；两条路径不可混用连接配置。
- 反向代理应允许至少 9MiB 请求体，并让 `/api/` 路径完整转发到当前 Python 后端。
- 在微信后台配置实际使用相册/相机及上传照片的隐私保护说明，完成真实设备上的授权、拒绝和恢复检查。
- 当前后端已启用微信登录和按用户任务隔离。正式发布前仍需验证真实用户的授权、退出、会话到期与请求配额，避免把本地调试配置直接用于运营。
- 在真机核对照片选择、后台恢复、编辑保存、原图与 Word，配置真实模型并核对内容后，再通过开发者工具上传体验版和提交审核。
