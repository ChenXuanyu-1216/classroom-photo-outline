# 中文课堂照片人工评分协议 v0.1

日期：2026-10-19。**本协议是新增的待试标口径，不是已经验收的质量标准或评分结果。** 文中的 N1/VH1 等标签是历史项目协议代号，不是本次开源发布已满足的质量门槛。数据准备与模板见[采集说明](../evaluation/classroom-photos/README.md)。

## 评分流程与单位

先冻结照片、授权用途、页序、页级期望、可辨认知识单元、不可读区域和重复组，再运行模型。页级识别、跨页合并、模块组织分别评分，不将同一错误反复加权为一个总分。保留未经人工编辑的第一次输出；重试和校对后结果分别登记，不用较好的一次替换失败记录。

两位标注者先独立制作页级期望，由裁决者解决分歧；再随机化输出编号，隐藏模型名称、提示词版本及另一人的分数，独立评分。评审可看冻结期望与照片；模型输入不能含金标准、评分备注或其他模型的答案。记录匿名人员 ID 和实际人数；一人完成只能称自评，不能声称双人复核。

关键错误、N/A 分歧、相差至少 2 分的维度必须裁决；其余差异同样保留并给出最终理由。裁决者不得抹掉原始两份评分。先用试标集检查理解是否一致、记录分歧率与标注耗时，再冻结正式协议；若正式评分中修订规则，升版本并统一重评受影响样本。

知识单元以运行前标注为准。模型文字先拆为最小事实单元，一对一匹配期望；一条含多个事实的句子应拆开，不能一次匹配多个期望而不检查各事实。正文允许不改变含义的表达差异；数学条件、代码语义及关键符号不能靠“意思相近”放宽。无依据的新事实单独计为不支持项，重复输出不增加召回。

内容覆盖分母采用 `expected_points` 中的知识单元；标题单独核对并在模块结构评分中使用，不重复当作知识点。若整页仅有可读标题，将其登记为一个有证据的期望单元并说明，不能将有可读内容的页标成全不可辨认。公式、代码检查引用所属知识点，不额外增加知识单元数量。

## 页级评分（结构化识别阶段）

每页填写[页级评分表](../evaluation/classroom-photos/templates/page-review.template.json)，注明实际取证阶段。仅有最终大纲时，识别阶段字段标为 `not_observed`，不能填作高分或 N/A；该页不能产生完整识别评分。最终大纲的删减不能反推 OCR 漏识别。

前三维只统计识别器原始 `structured.points` 通道；`text` 和 `structured.title` 是独立的转写、标题核对证据，不与 points 拼接计数，分别记录在 `transcription_notes/title_review`。内容单元由 points 的正文拆分；来源维度按全部 points 条目计，缺正文或缺来源字段的条目也保留在分母并判不正确。来源页核对程序给该页绑定的逻辑页码。若已确认原始 points 为空，即使 text 有内容，也按空结构化输出评分并注明契约缺口，不能人工从 text 补出 points 冒充模型结果；应用后续文本重建所得条目属于另一阶段，可另报告，不能混入此分母。

表中 `execution_status` 使用 `pending/success/failed`；维度 `status` 使用 `pending/scored/na/not_observed`，后两者的分数保持 null 并填写理由。`unit_matches` 每项记录 `expected_point_id/output_unit_id/correct/evidence`；`unsupported_output_units` 记录 `output_unit_id/output_excerpt/reason`。不可读区域评审记录 `region_id/observed_behavior/score/evidence`。原始事实单元与来源条目均给稳定输出 ID，保存在所引用的快照中，便于复核分子分母。

| 维度 | 计算依据 | 适用情况 |
| --- | --- | --- |
| 内容忠实度 | 正确且有本页证据的事实输出单元数 / 全部事实输出单元数 | 有可辨认期望时适用；公式、代码含关键错误的单元不算正确 |
| 内容覆盖 | 正确恢复的不同期望单元数 / 本页全部可辨认期望单元数 | 分母在运行前冻结；不可辨区域不进入可读召回分母 |
| 来源正确性 | 正文有证据且 `source_type`、来源页均正确的输出条目数 / 全部输出条目数 | 页内检查本页绑定；最终合并来源集合在跨页表另评 |
| 不确定性处置 | 逐个核对预标不可读区域及非预期编造 | 有不可读区域时适用；清晰页另行记录误报低清晰度次数 |

前三维度以比率映射到 0–4 分：**4 = 100%；3 = [90%,100%)；2 = [70%,90%)；1 = (0,70%)；0 = 0%**。记录原始分子、分母及匹配证据，不仅保留分数。有可读期望但空输出或处理失败时，前三维均按 0 分约定记录，分母为零的精确率原始比率仍为 null，注明 `empty_output`，不能算 N/A。

不确定性锚点：4 = 各不可读区域均明确指出、保留可读片段且不猜写；3 = 无臆造但定位较笼统；2 = 部分区域漏标、不含无证据补全；1 = 用“AI推断”等方式补写不可读内容；0 = 将猜写内容当课堂原话。多个区域取最低锚点并逐项记证据。处理失败或无提示的空输出不能当作正确弃答，适用时记 0。

适用性及例外判定规则在运行前冻结。没有不可读区域时，不确定性为 N/A。全页确实无可读期望时，覆盖恒为 N/A；正确弃答且无事实输出时，忠实度及来源为 N/A、不确定性按锚点评分；确认执行失败、无提示空输出或臆造时，忠实度与来源均为 0，不确定性按失败或臆造规则记分。仅缺阶段证据记 `not_observed`，不属于 N/A，也不等同已经证实的执行失败；暂不纳入完整评分并单报数量，后续补证，不静默丢弃。源转写中的猜写也属于不确定性与关键错误的核对对象，不能因未进入 points 而忽略。

页内描述性分数为 `100 × 适用维度得分和 / (4 × 适用维度数)`，全部 N/A 时为 null；任一适用维度 `not_observed` 时总分暂为 null。各维度与关键错误必须同时报告，**没有按总分宣告 N1 通过的门槛**。任务已执行而无可用输出的失败样本按上述零分规则保留，不能因失败剔除。

## 关键错误：不能被平均分抵消

| 类型 | 关键错误示例 | 判定要求 |
| --- | --- | --- |
| 公式 | 正负号、不等号、指数、上下标、括号范围、分子分母、求和或积分边界、适用条件改变 | LaTeX 与普通排版可等价，但数学对象与条件必须一致 |
| 代码 | 标识符大小写、字面量、运算符、缩进、语句顺序、循环边界改变逻辑 | 核对原图；功能摘要不能代替应恢复的代码，不能静默修正原图错误 |
| 来源 | AI 补充标课堂原话、猜写不可读原文、无依据绑定来源页 | 即使内容碰巧正确也不算图像证据支持 |

记录 `error_id/point_id/region_id/output_excerpt/expected/impact`。有关键错误的页或包含该错误的模块不能被判为“可直接用于复习”，仍保留所有原始得分。纯排版差异若不改数学或代码含义不属于关键错误。

## 跨页重复和来源（任务级）

使用冻结的重复组，一组计一次，成功须同时满足：恰好保留一条、正文及关键条件完整、来源类型正确、`source_pages` 与期望集合完全一致（无漏页、无多页）。报告正确组数 / 应合并组数；精确重复和语义近重复分开报告。没有重复组则 N/A，不当作 100%。

另评 `separation_groups`：相似但意义不同的知识点必须独立；同文不同 `source_type` 也必须保留独立。报告受检组数、误合并组数和证据。来源集合按任务逻辑页码比较，不按字符串顺序；同一重复组不再按页对数量多次计成功。

例子均是说明规则的文字，不是真实样本：`x > 0` 与 `x >= 0` 不能合并；代码 `value` 与 `Value` 不能仅因转小写而合并；字符串 `"a b"` 与 `"ab"` 不等价。同一句课堂原话和 AI 推断是两个来源组。当前实现未保证这些语义保护，错误须如实登记。

## 模块组织与 VH1

每个输出模块独立记录结构和复习可用性，采用以下 0–4 锚点：

| 分数 | 结构合理性 | 复习可用性 |
| --- | --- | --- |
| 4 | 标题准确、层次与主题一致、无错组 | 无需实质修改即可复习，内容、条件及来源完整 |
| 3 | 有少量标题或排列问题，主题仍清楚 | 少量文字或排列修订即可使用，无关键错误 |
| 2 | 多处混题或拆组，需要重新组织 | 需补充、删除或实质校正才能使用 |
| 1 | 大部分错组，主题难以理解 | 大部分内容需重写 |
| 0 | 空白、不可解析或无有效主题 | 无可用输出或内容误导 |

本轮操作化约定：两项均 ≥3 且无关键错误，模块才记 `pass=true`。这是对“结构合理、可用于复习”的新增定义，须经试标校准后冻结；不是原始基线已有的分值要求。

VH1 的原始分母是模块。本协议报告“通过模块 / 全部输出模块”；空白、无效、额外模块同样登记，关键错误模块不通过。全无模块时通过率为 0。为防只输出一个好模块掩盖漏课内容，必须另报冻结期望主题及知识点的覆盖、漏模块与漏点数；缺少覆盖证据时不下完整验收结论。不能改用照片数、知识点数或评审人数当 VH1 分母。

原文未规定 80% 是汇总还是逐课程计算，本协议同时报告两者，明确采用“每门课与汇总均 ≥80%”作为**拟议的保守判定**，经试标冻结前不宣称已成为原始要求。至少 3 门课、每门至少 15 个不同页面是原始前置要求；试标集不够。重复拍摄、降质衍生和重试不增加独立页数。N1 另给描述性质量基线，VH3 仍需用户指认来源样式并访谈，均不能由页级总分替代。

## 运行记录与报告

填写[任务运行表](../evaluation/classroom-photos/templates/run-review.template.json)，每名评分者保存一份并填写顶层 `rater_id`，该文件内所有任务级评分均归属于此人。记录实际识别器与归组器、模型和提示词版本、代码提交、有效上传配置、输入顺序与文件哈希、重试、失败、首次输出及校对版本、耗时、用量及证据路径。`configured_provider` 不等于 `actual_provider`；`provider_evidence_path` 引用脱敏的实际执行分支或请求记录。当前系统没有该审计记录的自动持久化；无证据时实际识别器记 `unknown`，不能仅凭配置、`/meta` 或置信度登记为真实识别。识别与归组提示词分别记录实际生效文本的版本/哈希，2026-10-20 的真实识别已加载版本化 YAML，并在页面结构化元数据中保存实际提供商、提示词版本、用量等信息；完整实验运行表仍需另行归档，未加载的 YAML 不算生效提示词。

模块记录字段：`module_id/output_heading/point_refs/structure_score/usability_score/critical_error_ids/pass/evidence/rater_id`。重复评审记录 `group_id/expected_source_pages/observed_source_pages/output_refs/success/reason`；分离组记录 `group_id/output_refs/incorrect_merge/reason`；期望主题记录 `topic_id/expected_point_refs/covered_point_refs/missing_point_refs`。页级、重复、分离和模块原始评审分别按评分者保存，裁决表引用原始记录路径并记录最终判定与理由。

报告真实课程和不同原始页数、各场景页数、自然/人工降质数、协议版本、适用/N/A/未观测/失败数、分维度结果、关键错误、去重和误合并、模块比例及遗漏。优先按课程、场景展示页级宏平均；重试不当新样本，页数多的课程不应掩盖其他课程。总体数字同时给分子分母与每课程结果，不用单一平均数证明全面可用。

VH2 单独用不超过 10 张的任务，记录从提交处理到可读大纲的墙钟耗时（包括识别、归组和实际重试），比较原始 ≤60 秒假设；模型调用超时设置不能代替端到端实测。本协议初版时首批照片与 AI 辅助期望草稿已登记，运行字段为 pending/null；后续真实质量试跑见历史记录（历史资料未随源码分发），不能与未完成的独立人工评分或访谈混为一谈。

2026-11-02 新增[网页评价入口](exp05-web-evaluation.md)，可保存计数、模块评分、错误证据和用户反馈。网页采用本协议的比率与单模块口径，但没有自动执行完整试标、双人标注、裁决、不确定性评分或 VH1 验收；正式结论仍须保留本协议要求的材料。
